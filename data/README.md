# Data

## Toy corpus

`data/demo_corpus.jsonl` is generated by:

```bash
python scripts/build_demo_corpus.py
```

The demo corpus is synthetic and must not be presented as scientific evidence.

## M3 real corpus — LLM agent evaluation (OpenAlex)

`data/llm_agent_eval_v1.jsonl` is a versioned snapshot of real literature
rebuilt by:

```bash
python scripts/build_real_corpus.py --limit 400
```

- **Domain**: works whose title matches "language model agents" (OpenAlex
  `title.search`), 2019-2025, sorted by relevance; only works with an
  abstract are kept (326 documents).
- **Source & license**: OpenAlex REST API — CC0 data, no API key required.
  Abstracts are reconstructed from `abstract_inverted_index` and reused for
  scholarly purposes under OpenAlex's terms of use.
- **Provenance**: `data/llm_agent_eval_v1.meta.json` records the query, fetch
  timestamp, counts, and exact reproduction command.
- **Default cutoff**: `2024-06-30` → 142 pre-cutoff (visible) /
  184 post-cutoff (hidden) documents.

Run the full method suite on the real corpus:

```bash
python scripts/run_llm_demo.py \
  --corpus data/llm_agent_eval_v1.jsonl \
  --corpus-version llm_agent_eval_v1 \
  --cutoff 2024-06-30 --tag real
```

## Required fields for any versioned corpus snapshot

- stable document ID;
- title;
- abstract or legally available full text;
- publication date;
- source;
- license/access status;
- retrieval timestamp;
- corpus version.

## Temporal rule

Post-cutoff documents must be physically or logically isolated from all agent-facing retrieval operations.

Do not construct a full-corpus index and merely filter results after retrieval unless you can prove that no future-derived statistics influence ranking.

The CounterGap retrieval backend (bag-of-words term counting) is deliberately
free of corpus-level statistics (no IDF/embeddings fitted on the full corpus),
so the temporal rule holds by construction.
