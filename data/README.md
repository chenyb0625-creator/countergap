# Data

`data/demo_corpus.jsonl` is generated by:

```bash
python scripts/build_demo_corpus.py
```

The demo corpus is synthetic and must not be presented as scientific evidence.

For a real experiment, create a versioned corpus snapshot with at least:

- stable document ID;
- title;
- abstract or legally available full text;
- publication date;
- source;
- license/access status;
- retrieval timestamp;
- corpus version.

## Temporal rule

Post-cutoff documents must be physically or logically isolated from all agent-facing retrieval operations.

Do not construct a full-corpus index and merely filter results after retrieval unless you can prove that no future-derived statistics influence ranking.
